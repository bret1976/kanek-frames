# KANEK FRAMES

Intelligence, built into the structure.

Marketing site for Kanek Frames — advanced structural steel with embedded digital intelligence (Kanek Core™, Digital Wireframe™, Kanek Grid™).

## Stack

TanStack Start · React 19 · Vite · Tailwind v4 · Vercel

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
